# 🚀 Antigravity Telegram Bot

Удаленный Telegram-бот для прямого общения с вашим локальным агентом **Google Antigravity (`agy`)**, запущенным на компьютере.

С помощью этого бота вы можете ставить задачи, писать и отлаживать код, запускать консольные команды на вашем ПК, просматривать файлы и проекты прямо со своего смартфона или любого устройства через Telegram!

---

## 🌟 Основные возможности

- 🧠 **Прямая интеграция с Antigravity CLI (`agy`)**: бот общается с официальным движком Antigravity на вашем ПК.
- 💾 **Сохранение контекста**: сессия продолжается от сообщения к сообщению. История хранится в локальной базе `data/sessions.db`.
- 🔄 **Управление диалогом**: команда `/new` или `/reset` мгновенно сбрасывает контекст и начинает новый диалог.
- 🎭 **Смена моделей прямо в чате**: переключайтесь между **Gemini 3.8 Flash**, **Gemini 3.1 Pro**, **Claude Sonnet 4.6**, **Claude Opus 4.6** и другими с помощью инлайн-кнопок по команде `/model`.
- 📁 **Смена рабочего пространства**: команда `/dir C:\путь\к\проекту` позволяет перенаправить агента в любую папку на ПК.
- 💻 **Режим выполнения команд**: агент может запускать скрипты, тесты и вносить изменения в файлы по вашему запросу.
- 📎 **Работа с файлами и скриншотами**: отправьте в бот файл (код, документ) или скриншот ошибки — бот сохранит его и передаст агенту для анализа.
- 📥 **Умная очередь сообщений**: если отправить несколько сообщений подряд, пока агент думает, они автоматически встают в очередь и выполняются последовательно с сохранением контекста. Каждый запрос можно отменить персональной кнопкой или командой `/queue`.
- 🔒 **Защита доступа (Whitelist)**: доступ к боту открыт только для указанных вами Telegram User ID в `.env`. Никто посторонний не сможет управлять вашим компьютером.

## ⚡ Быстрый старт за 3 шага

### Шаг 1. Создайте бота в Telegram
1. Откройте в Telegram официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям:
   - Придумайте имя для бота (например: `My Antigravity Assistant`)
   - Придумайте юзернейм, оканчивающийся на `bot` (например: `my_antigravity_bot`)
3. Скопируйте выданный токен API (вида `7123456789:AAH...`).

### Шаг 2. Узнайте свой Telegram ID
1. Откройте бота [@userinfobot](https://t.me/userinfobot) (или [@getmyid_bot](https://t.me/getmyid_bot)).
2. Он пришлет ваш цифровой ID (например: `123456789`).

### Шаг 3. Настройте файл `.env`
Откройте файл [.env](file:///C:/Users/Chatty/Projects/AntigravityTG/.env) в корне проекта и укажите:
```ini
TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
ALLOWED_USERS=ВАШ_ЦИФРОВОЙ_TELEGRAM_ID
```

*(Если вы хотите разрешить доступ нескольким людям, укажите их ID через запятую: `123456789,987654321`)*

### Шаг 4. Запустите бота
Просто дважды кликните по файлу [start.bat](file:///C:/Users/Chatty/Projects/AntigravityTG/start.bat) или выполните в консоли:
```powershell
.\start.bat
```

После этого откройте вашего бота в Telegram и отправьте `/start`! 🎉

## 📋 Команды бота

| Команда | Описание |
| :--- | :--- |
| `/project <название>` | Создать новую форумную тему для отдельного проекта в группе Telegram |
| `/projects` или `/topics` | Список всех проектов/тем в группе с их папками и текущим статусом |
| `/closetopic` или `/close` | Закрыть текущую тему проекта в Telegram |
| `/reopentopic` | Заново открыть ранее закрытую тему проекта |
| `/start` | Приветствие, проверка связи и карточка текущей сессии с темой диалога |
| `/new` или `/reset` | Начать новый диалог (очистить контекст и историю в этой теме) |
| `/resume` | Интерактивный выбор сохраненных диалогов по **темам** с показом прошлого ответа |
| `/topic <название>` | Задать или переименовать тему проекта (обновляет название и в Telegram) |
| `/status` | Показать карточку статуса (тема, модель, effort, режим, CWD, статус процесса) |
| `/model` | Меню выбора нейросети (Gemini 3.8 Flash, Pro, Claude Sonnet/Opus, GPT-OSS) |
| `/effort` | Меню выбора глубины рассуждений (`low`, `medium`, `high`, `xhigh`, `max`) |
| `/mode` | Переключение режимов (`accept-edits` правки кода или `plan` планирование) и авто-прав |
| `/dir` | Показать текущую папку, список вложенных папок и интерактивные кнопки навигации |
| `/dir <название>` | Открыть вложенную папку по имени (относительно текущей открытой) |
| `/dir <полный_путь>` | Открыть любой абсолютный путь (например: `/dir C:\Users\Chatty\Projects`) |
| `/dir ..` | Подняться на один уровень выше |
| `/sh <команда>` | Прямое выполнение консольной команды на ПК (PowerShell) |
| `/queue` или `/q` | Просмотр очереди сообщений в текущей теме и кнопка очистки |
| `/stop` или `/cancel` | Мгновенно прервать текущую задачу агента и очистить очередь в этой теме |
| `/help` | Полная справка по возможностям |

## 🏗 Параллельная работа над несколькими проектами (Темы в Telegram)

Бот поддерживает нативные **форумные темы (Forum Topics)** Telegram:
1. Создайте закрытую группу в Telegram (например, `Antigravity Workspace`).
2. В настройках группы включите переключатель **«Темы» (Topics / Форумы)**.
3. Добавьте бота в группу и назначьте его администратором с правом **«Управление темами»**.
4. Теперь вы можете создавать отдельные темы для каждого проекта командой `/project Backend API` или `/project Frontend React`.

**Преимущества тем:**
- **Изоляция:** каждая тема имеет свою рабочую директорию (`/dir`), независимый контекст Antigravity и выбранную модель.
- **Параллельность:** задачи в разных темах выполняются одновременно, не блокируя друг друга!
- **Остановка:** команда `/stop` прерывает расчет только в текущей теме.

### ⚡ Встроенные слэш-команды Antigravity:
Любая команда Antigravity CLI поддерживается напрямую:
- `/skills` — показать установленные навыки
- `/usage` (или `/quota`) — проверить расход токенов
- `/credits` — баланс кредитов
- `/agents` — список доступных субагентов
- `/permissions` — аудит прав инструментов
- `/changelog` — журнал изменений

## 📝 Стандарты оформления сообщений

Все сообщения оформляются в виде структурированных **статей** по спецификации [Telegram Formatting Options](https://core.telegram.org/bots/api#formatting-options):
- **Заголовки** (`<b><u>...</u></b>` и `<b>...</b>`) для четкого разделения блоков.
- **Блоки кода** (`<pre><code class="language-...">`) с подсветкой синтаксиса для нужного языка программирования.
- **Раскрывающиеся цитаты** (`<blockquote expandable>`) для логов, заметок и пояснений.
- **Умное разбиение**: длинные ответы разбиваются на части с автоматическим закрытием и переоткрытием тегов без потери форматирования.
